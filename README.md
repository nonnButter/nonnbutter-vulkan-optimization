Hate having low FPS? Then this Modpack is for you!

What does this modpack do?
-
It adds Performance Mods like VulkanMod und Lithium while keeping the vanilla feeling and readds the old minecraft textures.
It also adds Quality of Life mods.

What do you need?
-
You need a Launcher compatible with .mrpack files.
You need a GPU that is compatible with Vulkan 1.2 or newer.
